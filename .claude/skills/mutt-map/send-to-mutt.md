# Send to Mutt (Share menu)

Part of the map of how Mutt is built (`CLAUDE.md`, Architecture, lists every file). Keep it current when this feature changes.

- Send to Mutt from the Share menu (2026-11-16): an Apple shortcut (`public/assets/send-to-mutt.shortcut`, built and signed on a Mac by `tools/make_shortcut.py`; it asks for Mutt's address and a key when added) sends each file to `POST /api/send` (auth-free route: the key in `Authorization: Bearer mutt-…`, the name in `X-Mutt-Name` plus `X-Mutt-Ext`, the bytes as the body, with or without a length first: `stream_to_file` in `web.py` also reads a chunked body; the cookie is never read there) and shows the `said` line it answers. The file is kept by `store_upload` (shared with `/api/upload`) and sorted as if dropped in the void; a picture instead waits as a star with `meta.sortWhenSeen` until `see.js` `catchUp` has read it, then sorts (`sortSent`). Keys: one per device in `send_keys` (only the hash; `auth.send_key_user`; up to `SEND_KEYS_MOST` 10), made by `POST /api/me/send-key`, all ended by `DELETE`; `sendKeys` (how many) comes with `/api/me`; a key can do nothing but send. Front end: the account sheet's `Share menu` door (`statusbar.js`), `setUpShareMenu` / `turnOffShareMenu` in `account.js`. Your data.json: `account.shareMenuKeys` (dates only). Checks: the foot of `tests/lockout.sh`, browser path `share_menu`.
