# Sound

Part of the map of how Mutt is built (`CLAUDE.md`, Architecture, lists every file). Keep it current when this feature changes.

- Sound (2026-11-16, `DESIGN.md` "Sound"): `sound.js` (always loaded: `sound`, `holdSound`, `audio()` the one sound clock shared with `music.js`, `startSound()` from `main.js`: wakes the clock on each pointer-down and key, plays `press` for a plain click of a button with no sound of its own, `on`/`off` for switches, rests it after 15 quiet seconds; a page change's sound is passed as `moving` to `transition`, a room's through `whenMoving`, so it starts with the movement) and `soundbank.js` (fetched when the page is idle and only while the `sound` pref is on: every sound, made on the device from clicks, knocks and air, their loudness `TRIM`, and the rules for many at once). Callers: `ui.js` (sheets, dialogs, menus, segmented, stepper, slider, toasts, rooms, the code pad), `statusbar.js` (the Sounds row, search), `router.js` (dive, surface), `planets.js`/`blackhole.js` (land, take, the void's swoop), `grid.js`/`listmode.js`/`board.js` (rearranging: lift, shift, drop), `drag.js` (lift, over, drop), `views/galaxy.js` (born, wind, the ring's detent), `viewer.js`, `listmode.js`, `actions.js`, `constellations.js`, `commentnotes.js`, `gravity.js`, `reader.js`, `quotes.js`, `views/login.js`, `account.js`, `resets.js`, `main.js` (files from the computer). `soundsHeard()` is for the browser path `sounds`. A browser driven by a test plays everything into a silent end (`speakers()`, read by `soundsLoudest()`), so the owner never hears tests.
