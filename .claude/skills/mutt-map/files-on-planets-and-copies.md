# Files on several planets, saved copies

Part of the map of how Mutt is built (`CLAUDE.md`, Architecture, lists every file). Keep it current when this feature changes.

- Files on more than one planet (front end and server): every file on a planet page carries `alsoOn` (the other planets and moons it is on that the viewer can open; `also_on` in `mutt/api.py`, called by `blocks_in_drawer`), shown as dots in its caption (`cells.js`) and as "Also on" in the file view (`viewer.js`; each opens the same file there, `/p/<id>?b=<file>`); `collection.js` keeps it current from the `connections` that come with `block:connected` / `block:disconnected`. `/api/galaxy[/user]` carries `threads` ({a, b, n}: planets that share n files, moons counted as their planet, only planets the viewer can open; `planet_threads`), painted as wisps by `views/galaxy.js` (`threadCurve`, `drawThreads`, `paintThreads`) with `wisp()` from `uvweb.js`. `/api/galaxies` carries `links` ({a, b, n} by username: galaxies sharing a file, either the same file on both or a saved copy, `meta.savedFrom`, both on planets the viewer can open; `galaxy_links`); the universe seats those side by side (`seat`, `gather`) and joins them with a wisp in its web.
- Saved copies and who made them (2026-11-15): saving someone's file (`POST /api/blocks/<id>/save`) makes a copy carrying `meta.savedFrom` {id, username} (whom it was saved from) and `meta.madeBy` {id, username} (the first file and its maker, carried on through copies of copies; older copies without it are followed back along `savedFrom`, `saved_copies` / `first_of` in `mutt/api.py`). `GET /api/blocks/<id>` adds `story` (`file_story`: `madeBy`, `savedBy`, `savedFrom`, `savedAt` for a copy, and `elsewhere`, every other copy's planets the viewer can open with whose they are, plus the viewer's own copy kept as a star) and `ownerName`; the file view shows them to everyone (`metaRows`, `elsewhere` in `viewer.js`). The universe's `links` (`galaxy_links`) always join a copy's saver to whom they saved from, wherever the copy sits, when the viewer can see the copy (on a planet they can open, or it's theirs); someone else's copy kept as a star never shows.
