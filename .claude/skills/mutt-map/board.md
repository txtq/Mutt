# Board mode

Part of the map of how Mutt is built (`CLAUDE.md`, Architecture, lists every file). Keep it current when this feature changes.

- Board (`drawers.modes.board` {on, dismissed}, the sixth planet mode, moons too; 2026-11-16, `DESIGN.md` "Board"): offered by what the owner does, not by what the files are. `PUT /api/drawers/<id>/order` with `hand: true` (sent only by `collection.js` `onReorder`/`sendTo`, never by Undo or uploads) adds a row to `hand_moves` when the order really changed and no showing mode is on (`note_hand_move`, kept a month); `read_board` in `mutt/modes.py` fits (is offered) at `BOARD_MOVES` 8 in `BOARD_DAYS` 14, on any days, with `BOARD_FILES` 4; it also returns `always` (2+ files, `BOARD_ANY`), which puts `Make it a board` in the ••• menu before any offer (`modeItems` in `views/planet.js`; the one mode the user asked to be choosable, 2026-11-16). Its entry has `keeps=True`: once answered (on or waved away) it always fits, so it never steps back by itself. Where things sit is `board_items` (drawer, item = a file id or `w-…` for the board's own words, x, y, w, h, z, words, style heading|label) and the lines `board_lines` (a, b sorted); a file taken off the planet keeps its row for when it comes back. `GET /api/drawers/<id>/board` (anyone who can see the planet; with `?arrange=1` its owner, while no file has a place, also gets `groups` by subject from `split.groups`, which `arrange`/`groupsOf` in `board.js` lay out, else by kind), `PUT` (owner: {items, gone, join, part}; numbers clamped to `BOARD_REACH`, at most `BOARD_MOST` things, words up to `BOARD_WORDS`). The download puts each planet's `board` in `Your data.json`. Front end: `board.js` (`BoardView`, `gridRects`: the view, near things only, the lines on one canvas with `wisp`, carrying, resizing, words, joining, pinch and wheel, the keyboard; it always opens fitted to its files; the collage layout `layoutFor`/`masonry`/`spans`, used by a new board, the bar's Arrange menu (`rearrange`, `lay`; `?groups=1` gives the owner the subjects any time) and once by itself for a board that had become a long line or a heap (`messy`); its choices and `laid` are the board mode's settings `order`/`sizes`/`laid`; new files go to the foot of the shallowest column (`slot`, `placeNew`); ⌘Z walks back `history`) and `board.css`, fetched only when a planet is one. Checks: the board block at the foot of `tests/modes.sh`, browser path `board_mode`.
