# Throw to Sort

Part of the map of how Mutt is built (`CLAUDE.md`, Architecture, lists every file). Keep it current when this feature changes.

- Throw to Sort (2026-11-16, `DESIGN.md` "Throwing"): `fling.js` (`tracker`, `isFlick`, `aim`, `fly`, `comeBack`, `landed`). `drag.js` takes `onThrow` (a flick let go over no target, or over the void when aimed at a world beyond); `views/galaxy.js` `throwStar` puts a star on a planet or moon (`putOn`, which gives "Put on X" with an Undo, `takeBack`, that also rejoins its constellation) or into the void (`dropStar`). On a planet page `grid.js` `throwTo` throws a box at the `targets` (moons, or a moon's planet) through `onDropTo(target, id, { thrown })` (`Collection.moveTo` answers true/false). The landing ring is `.is-landing` on `.planet-body` / `.moon` in THE DROP RING. Browser path `throw_star`. On a planet you arrange, the back arrow in the top-left corner is a target too: one of your files carried or thrown there comes off the planet and is a star again (`skyTarget`, `toSky` and `homeCatches` in `collection.js`; grid targets now get the carried file's id); browser path `drag_to_star`. A file's last planet is said wherever it can be left (`lastPlanet` in `actions.js`: the menu hint "Becomes a star", the toast "Now a star in your galaxy", the file view's "Make it a star").
