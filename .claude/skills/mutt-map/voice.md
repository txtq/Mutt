# Speak to the Void

Part of the map of how Mutt is built (`CLAUDE.md`, Architecture, lists every file). Keep it current when this feature changes.

- Speak to the Void (2026-11-16, `DESIGN.md` "Speak to the Void"): holding the void (`blackhole.js`, `onHold` → `{ slide(k), end(drop) }`, `say()`, `listening()`, `loudness()`) runs `holdVoid` / `letGoVoid` / `keepVoice` / `readVoice` / `catchUpVoices` in `views/galaxy.js`. `voice.js` (fetched on the first hold) records with MediaRecorder, keeps the sound's shape (64 levels, `meta.voice.wave`), hushes `music.js` (`hush`) and asks `hear-worker.js` for the words: Moonshine Tiny with onnxruntime-web from cdnjs, its model served by Mutt (`mutt/hear.py`: fetched once into `DATA_DIR/models`, sha-checked; `/api/hear/encoder|decoder|vocab`; `MUTT_HEAR=0` turns it off, `MUTT_HEAR_DIR` points at a local copy; tests run with it off) and kept in the browser's cache storage. Only the words are saved (`meta.heard` {v, text}; `PATCH /api/blocks/<id>` takes `voice` and `heard` on sound files only), read by `sorting` like a note's text and found by search. `GET /api/hear/todo` lists recordings whose words weren't read yet. Its star is `.star.is-voice` with `--rays` (`raysOf` in `planets.js`); its face `voiceFace` (`planets.js`) and the file box's voice branch (`cells.js`); the file view's `voiceStage` (`viewer.js`). The checks are at the foot of `tests/search.sh`.
